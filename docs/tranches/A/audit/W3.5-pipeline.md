## §3 — Refinements applied

### §3.1 Heap-driven Visvalingam–Whyatt

File: `web/src/lib/contourEditing.ts:72-188`

**Before** (lines 107-132 of prior revision): linear scan over `nodes[]` on
every removal, computing `triangleArea` on the fly. With `n=1024` default
points and `removalFraction=0.2`, the inner loop executed ~52 million area
comparisons.

**After**: indexed binary min-heap keyed by triangle area. Build is O(n);
each `extract-min + splice + re-key two neighbours` is O(log n); total
O(n log n). Parallel typed arrays (`Float64Array` / `Int32Array` /
`Uint8Array`) replace the per-node object allocations. Inner loop holds in
~16 KB of working set for n=1024.

### §3.2 Single-pass epicycle position computation

File: `web/src/components/visualization/BasisCanvas.vue:134-150` and
`315-335`

**Before**: `fourierPositionsAt(components, anim.t, components.length)`
followed by `fourierPositionsAt(components, anim.t, nVis)` per frame —
two full traversals over the same component chain.

**After**: one pass over the full chain; the visible-circles overlay is
`allPositions.slice(0, nVis + 1)`. Identity-equality short-circuit when
`nVis === components.length`. At 60 fps with N=200 components, this
reclaims ~24 000 ops/sec of unproductive multiplication.

### §3.3 Auto-compute deduplication

File: `web/src/components/visualization/composables/useWorkspaceLoader.ts:80-97`

**Before**: `useWorkspaceLoader.ts:89-104` watched `store.contour` and
fired `store.computeEpicycles()` on every contour mutation, while
`ContourSettings.vue:148-167` independently watched settings and triggered
the same compute path on `imageMeta` arrival. Both fired on fresh upload;
the loser's request landed in the network as `ERR_ABORTED`.

**After**: the duplicate watcher is discharged with a docstring rationale
in `useWorkspaceLoader.ts`; `ContourSettings.vue` becomes the sole
auto-compute seam.

### §3.4 nHarmonics reset gating

File: `web/src/components/visualization/composables/useWorkspaceLoader.ts:80-94`

**Before**: `watch(() => store.imageSlug, () => { nHarmonics.value =
CONTOUR_DEFAULTS.n_harmonics })` fired on the initial slug assignment from
`loadWorkspace`, clobbering the draft-seeded value set by the `{ once:
true }` watcher on `store.contourSettings`.

**After**: `priorSlug` closure variable initialised to the current store
value; the watcher only fires when `priorSlug !== null && slug !==
priorSlug` — true only for mid-session image swaps, never for initial
mount.

### §3.5 Dead-substrate excision

File: `web/src/stores/animation.ts:1-28`

Removed `import { Animation } from "@mkbabb/keyframes.js"`, the `anim`
module variable, and the `createAnim()` factory. Never invoked since the
manual-rAF migration (see history of `startLoop()` / `tick()`).

## §5 — Residual items

### Routed to **B** (CRUD convergence)
- **Levels derivation drift** between `workspace.runComputeBases` and
  `computation.compute_bases` — lift to a single seam in the request model
  so the front-end no longer constructs an `Array.from` levels list.

### Routed to **C** (infra + image-blob absorption)
- **Backend `--reload` drops in-flight compute on file write** — either
  disable `--reload` for the dev container or route long compute jobs
  through a background worker so source-file edits do not abort active
  requests.
- **onnxruntime CPU-vendor warning flood** in backend logs — silence at
  process start.

### Routed to **W3.5.ab** (style.css owner)
- `web/src/style.css:3` `@import "@mkbabb/glass-ui/styles"` requires a
  `pnpm vite optimize --force` to resolve through the package `exports`
  map on cold dev-server boot. Either pin the explicit subpath
  (`@import "@mkbabb/glass-ui/dist/styles/index.css"` once the package
  exports `./dist/*`) or add a `resolve.alias` carve-out — the contract-v2
  precept presently disallows the latter.

### Out-of-bounds (left for owning agents)
- `MobileFloatingToc.vue` + `PaperSidebar.vue` — W3.5.c paper view; my
  edits would have shadowed an in-flight refactor.
- W4.b's contour-hash narrow fix in `api/services/image_storage.py` — left
  intact (the broader hash discriminator at `compute_contour_hash` already
  preserves vertex ordering, matching W4.b's intent).
