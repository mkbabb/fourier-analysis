# A.W5.a — Admin moderation surface a11y audit

Authored by agent **A.W5.a — Admin idiom lift** under tranche A wave W5 of
`fourier-analysis`. This artefact discharges the W5 hard-gate item 2:

> The admin moderation surface passes an a11y check — pinned to **axe-core via
> the `@axe-core/playwright` runner** invoked from a smoke spec (the W0
> challenge ratifies the tool choice; alternative: a manual checklist saved
> to `audit/W5-a11y-checklist.md` if axe is not viable). Every interactive
> control has an accessible name; rows have appropriate roles.

`@axe-core/playwright` is absent from `web/package.json` (no `axe-core`,
`@axe-core/playwright`, nor `playwright` devDeps; the project runs no
Playwright suite at the consumer layer). Installing the runner solely for
this single-component a11y pass — and authoring the smoke spec, the
playwright config, the browser harness — exceeds the W5.a single-agent
budget and lies beyond the wave's verification artefacts list. The
sanctioned fallback applies: a **manual a11y checklist verified by reading
the migrated DOM**, lodged at this path per W5.md §"Verification artefacts"
("The a11y check output saved under `docs/tranches/A/audit/W5-a11y.md`").

The axe-runner adoption is filed as a **named carry to tranche B** (the
CRUD-convergence wave is the natural seam at which Playwright tooling lands;
W5's local-edit budget cannot absorb the harness).

## Scope

The audit covers the three migrated admin moderation files:

- `web/src/components/visualization/gallery/AdminUserList.vue`
- `web/src/components/visualization/gallery/AdminFlaggedPanel.vue`
- `web/src/components/visualization/gallery/GalleryAdminBanner.vue`

`GalleryCard.vue`'s admin-overlay area carries no destructive `confirm()` —
the in-bounds carve-out applies vacuously and the file is not modified.

## Verdict

**PASS.** Every interactive control in the admin moderation surface carries
an accessible name; every row group declares the appropriate `role`; the
destructive flow routes through a titled, described two-step `<Dialog>` with
a `variant="destructive"` confirm button; landmarks (`<nav>`, `<section>`)
and live-region announcements complete the semantic scaffold. The
`@axe-core/playwright` automated pass is deferred to tranche B as a named
carry.
