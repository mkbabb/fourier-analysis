## The transposition — LCP-path third-party origins 3 → 0
The first paint reached THREE render-blocking third-party origins; all now same-origin:
1. **KaTeX CSS** (was jsdelivr `katex@0.16.21`) → bundler-native `import "katex/dist/katex.min.css"` in `web/src/main.ts`; Vite fingerprints it + emits **19 `KaTeX_*.woff2`** into `dist/assets/`, same-origin. Also **fixes the 0.16.21↔0.16.47 pin drift** (now tracks the npm dep).
2. **Computer-Modern Serif** (was jsdelivr `cm-web-fonts@333f55e`) → vendored under `web/public/fonts/Serif/` + `web/public/fonts.css`. **Upstream ships only `woff` (all `cmun*.woff2` 404)** — so vendored `woff` with correct `format("woff")`. All 4 faces declared `font-family: "Computer Modern Serif"` (exact match to `--font-sans`, `web/src/style.css:14` — no Georgia fallback): cmunrm (regular), cmunbx (bold), cmunti (italic), cmunbi (bold-italic).
3. **Google Fonts** (Fraunces display + Fira Code mono) → vendored woff2 (latin subset, `unicode-range` preserved, `font-display: swap`) under `web/public/fonts/{fraunces,fira-code}/`.
- `web/index.html`: deleted all 3 third-party `<link>`s + all 3 preconnects; repointed the 3 CM preloads to same-origin `/fonts/Serif/cmun*.woff` (dropped `crossorigin`); single `<link rel="stylesheet" href="/fonts.css">`. **meta-description preserved** (W1's δ item intact).
- `web/vite.config.ts`: NO change (public/ copies verbatim; katex already in `manualChunks vendor-math`).

**Committed-binary cost**: 726.6 KiB (4 CM woff + 2 Fraunces woff2 + 1 Fira Code woff2). KaTeX woff2 are bundler-emitted (never in git).
