## Operational lesson + residuals booked
- **nginx bind-mount inode staleness (→ W7 deploy-hook).** The auto-deploy `git pull` replaces `nginx/fourier.conf` via atomic rename (new inode); the running nginx container's single-file bind-mount keeps the OLD inode, so the new config is INVISIBLE to `nginx -t`/reload until the container is **recreated**. `--force-recreate nginx` was required to activate `real_ip`. The deploy-hook does only `up -d` (won't recreate an unchanged service def) → **every nginx config change is silently not applied by the auto-deploy.** Booked for **W7 (ε.2 deploy-hook convergence)**: detect an `nginx/` diff in the pull and `--force-recreate nginx`.
