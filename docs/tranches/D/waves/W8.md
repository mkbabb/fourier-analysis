## §2 — Stratum A: repo-local deliverables (the script + the artefact)

### §2.1 — `scripts/cf-dns.{sh,py}` (tracked, new) — the idempotent CF-API script

W8 authors a tracked `scripts/cf-dns.sh` (bash + `curl` + `jq`) or `scripts/cf-dns.py` (Python + `requests`; choose whichever the agent finds smallest — both are KISS-honest, NA6 §1(a)). The script:

1. **Reads the token from env** — `: "${CLOUDFLARE_API_TOKEN:?Set CLOUDFLARE_API_TOKEN}"` (the speedtest fail-fast contract, NA2 §1.9). The operator sources the host `.env` before invoking: `set -a && source .env && set +a && bash scripts/cf-dns.sh`. **No token value in the script.**
2. **Resolves `zone_id`** — `GET /zones?name=babb.dev` → `.result[0].id`. The zone ID is read at runtime, not hardcoded (drift-safe).
3. **Declares the target set as data** — a flat list of `{name, type, content, proxied}` tuples, ordered for human review. The list is what the agent (or a future operator) reads to see the intent; the API calls follow it.
4. **Lists current records** — `GET /zones/{zone_id}/dns_records?per_page=100` → maps `(name, type) → {id, content, proxied}`.
5. **Per target tuple**, compares current ↔ desired:
   - If absent: `POST /zones/{zone_id}/dns_records` create.
   - If present + identical: **NO-OP** (log + skip — idempotency proof).
   - If present + differing in `content` or `proxied`: `PATCH /zones/{zone_id}/dns_records/{id}` update (NOT DELETE-then-CREATE, which races + risks NXDOMAIN at the edge mid-flip).
6. **Never touches records outside the target list** — the script's loop iterates the **target** list, not the current list. Records the script does not name are left alone. The don't-break invariants (MX, SPF, NS, apex A/AAAA, `*.babb.dev` wildcard, the existing `color`/`keyframes` GH-Pages CNAMEs until W9 deliberately flips them) survive by construction.
7. **Captures a dig-transcript** — at end of run, the script emits `dig +short` queries for every target name + the don't-break list, writing to `scripts/cf-dns-transcript.txt` (gitignored alongside `.env`; the FINAL.md cites the file's content but not the file itself).
8. **No secret in the script**; **no `set -x`** without scrubbing (a `set -x` echoes `$CLOUDFLARE_API_TOKEN` in any `curl -H "Authorization: Bearer …"` line) — use `curl --silent --header "@-" <<<"Authorization: Bearer ${CLOUDFLARE_API_TOKEN}"` form or invoke a small helper that does not echo the header.

The script is **declarative** in the target set, **imperative** in the per-record diff-then-PATCH — the smallest-honest-mechanism between "manual dashboard" and "full Terraform IaC" (NA6 §1(a) trap-to-reject: full Terraform / Pulumi for ~9 records on one zone).

### §2.2 — `.env` discipline — the credential boundary

The CF token lives **only** in (a) the host `fourier-analysis/.env` (`0600`, `mbabb:mbabb`, `git check-ignore .env` reports ignored), **and** (b) the GitHub Actions secret store as `CLOUDFLARE_API_TOKEN` (referenced by name only in any CI workflow that lands at W9). The user's directive (`D.md §7`; `PROGRESS.md` 2026-05-27 resolution entry): **NOT rotated**; saved per user direction; held there indefinitely; rotated only on suspicion. NA6 §2.3's "rotate after migration" recommendation is **explicitly overridden** by the user — the close ledger records the override, never silently complies.

**Verification at W8 close**:
- `git check-ignore .env` → exit 0 + prints `.env`.
- `git status` shows no `.env` tracked or staged.
- `git grep -nE 'CLOUDFLARE_API_TOKEN[[:space:]]*=' -- ':!*.md' ':!docs/**' ':!.env.example'` returns **zero hits with a literal value** — only `${CLOUDFLARE_API_TOKEN:?…}` references.
- `.env.example` may carry a placeholder line `CLOUDFLARE_API_TOKEN=` (empty), documenting the name; no value committed.

### §2.4 — The don't-break catalogue (binding; recorded inline so the script's reviewer cannot miss it)

`scripts/cf-dns.{sh,py}` carries a header comment block listing the **never-touch** records — preserved verbatim from NA3 §6.2:

1. **MX records** — `aspmx.l.google.com` (pri 1), `alt1`/`alt2` (5), `alt3`/`alt4` (10) — Google Workspace mail; touching breaks delivery.
2. **SPF TXT** — `v=spf1 include:_spf.google.com ~all` — paired with the MX.
3. **DKIM `*._domainkey` / DMARC `_dmarc`** — enumerate before any TXT edit (NA3 §6.2 caveat).
4. **Apex `babb.dev` A=`198.185.159.144`** (Squarespace 302→github) + the CF-flattened AAAA — Squarespace residue, functional, do not orphan.
5. **`www.babb.dev`** — identical 302 behaviour; same treatment.
6. **NS records** — `jillian/maciej.ns.cloudflare.com` — the delegation itself.
7. **`*.babb.dev` wildcard** — the proxied default catch + cert holder; revisit only after every live app has an explicit record.
8. **The existing `color.babb.dev` + `keyframes.babb.dev` grey CNAMEs to `mkbabb.github.io`** — kept until W9 deliberately flips them; W8 does NOT pre-flip them.

The script's target-list iteration explicitly skips any name matching the don't-break catalogue (defensive: even if a target tuple is mis-authored to one of these names, the script refuses to PATCH it).

## §3 — Stratum B: host-coupled execution (the script is RUN from the host)

The script is repo-tracked + reviewable but **runs from the host** (or from the operator's workstation with the host `.env` sourced). The run produces:

- A **stdout transcript** of every diff + every API call's status (no record IDs leaked beyond the script's own use; the auth header is masked in any `set -x` output by the helper).
- A **dig-transcript** capturing pre-run and post-run state for the in-scope names + the don't-break list (the regression evidence).
- **No secret leak** — `journalctl` / shell history shows no `CLOUDFLARE_API_TOKEN=` literal; the script reads from env, not args.

The run is performed **after** Wχ-P5 closes (the α′ probes) and **before** W9-fourier-pilot's CF Pages project creation (W9 needs the `fourier.babb.dev` custom-domain attach, which CF auto-CNAME-creates iff DNS resolves to the Pages target — but the pilot run only lands the **`api.fourier.babb.dev`** record; the `fourier.babb.dev` CNAME flip lands after W9 verifies on `fourier.pages.dev`).

| Token absent | the `${CLOUDFLARE_API_TOKEN:?…}` fail-fast aborts before any network call (NA2 §1.9 discipline). |
| Token present but lacks DNS:Edit | the first `GET /zones?name=babb.dev` succeeds (Zone:Read), but the first `POST /dns_records` returns `403`. The script logs the failure with the response body and exits non-zero. **Do not retry**; do not silently degrade. |
| Network failure mid-run | the diff-then-PATCH loop is per-record; a failure on record N leaves N+1..end un-touched and exits non-zero. The next run resumes (idempotency proof — already-landed records are no-op'd; un-landed records retry). |
| A target tuple's name matches the don't-break catalogue | the script's defensive guard refuses the PATCH + exits non-zero with a clear message. The catalogue is the safety belt. |
| Wildcard catches a name the script later wants to add explicitly | adding an explicit record for a name covered by the wildcard is **safe** — CF DNS resolves explicit before wildcard. The wildcard stays; the explicit record takes precedence. |
| The host `.env` has the token but `set -a && source .env` mis-export | the script's env-read fails fast (G2-pattern). Operator re-sources cleanly. |
