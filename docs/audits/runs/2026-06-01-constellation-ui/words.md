# words frontend — glass-ui design-canon audit

**Target:** `floridify-frontend` at `/Users/mkbabb/Programming/words/frontend` (148 Vue/CSS files).
**Consumes:** `@mkbabb/glass-ui@^2.0.0` (declared). Audited against glass-ui canon at rev `21547de` / pkg `3.0.0` (the working tree of `/Users/mkbabb/Programming/glass-ui`). `node_modules/@mkbabb/glass-ui` is not installed in the target, so the resolved runtime version could not be pinned; the `^2.0.0` floor against a `3.0.0` canon means several v3 tokens cited below (e.g. `--surface-tint-*`, `--type-display-*`, five-tier glass ladder) may not yet be present in the version words actually links — flagged inline where it changes a finding.
**Consumption shape:** words imports glass-ui UI primitives (`Button`×27, `cn`×14, `HoverCard`×12, `Tooltip`×8, `Card`/`CardContent`×9, `Popover`×5, `DropdownMenu`×4, `Dialog`×2, `Tabs`, `Accordion`, `Select`, `Skeleton`, `Toaster`, `useToast`) but keeps its **own** large `src/components/custom/` layer (~140 SFCs) and its **own** style tree (`src/assets/{index,theme,transitions}.css`, `src/assets/themed-cards/*`, `src/styles/ios-pwa.css`). It does NOT import glass-ui's `custom/*` components. ## Glass-ui gaps (patterns words legitimately needs that canon doesn't expose)

- **G1 — AI / saturated-accent register.** words hard-codes `--ai-accent` (gold-ish `#fbbf24`/`#d97706`) and a *more-saturated* gold (`--color-gold` hsl 43 90% 55%) across **115 sites** because the canon `--gold` (hsl 43 74% 49%) reads too muted for its "AI-enhanced" highlight + featured-word register. Canon has `--gold`/`--gold-light`/`--gold-dark` and `--tier-featured` (hsl 45 100% 50%) but no "AI accent" semantic. *Proposal:* either document `--tier-featured`/`--gold-light` as the AI-highlight handle, or add a `--accent-ai` semantic to tokens.css §6 so the 115 sites stop forking the gold value. Cite: `theme.css:11,15`; `text-[var(--color-gold)]`×30, `bg-[var(--color-gold)]/10`×8.
- **G2 — Metallic tier theming (gold/silver/bronze mastery).** `themed-cards/{variables,card-base,hovercard,effects}.css` (~377 lines) builds a per-tier metallic gradient + paper-texture overlay card, driven by `--theme-gradient-{start,mid,end}` on Tailwind amber/gray/orange palettes. This is a coherent, reusable widget pattern (a "MedalCard"/"TierSurface") repeated across mastery, review, and wordlist surfaces — a strong component+token candidate. Canon has `--gold*` and the 13-stop section-palette but no silver/bronze and no metallic-overlay recipe. *Proposal:* a `custom/tier-surface` component + `--metal-{gold,silver,bronze}-{start,mid,end}` token family in glass-ui, re-based on section-palette/gold. Cite: `themed-cards/variables.css:4-75`, `card-base.css:5-60`.
- **G3 — Static (non-button) pill / inline-badge chrome.** words references `.inline-pill` 5× (undefined in canon and locally) and hand-inlines `rounded-full border-2 border-background bg-background/96 shadow-cartoon-sm` circular badges ~19×. Canon has `.btn-pill` (interactive) and `.metric-pill`/`<Badge>` but no plain decorative inline-pill utility. *Proposal:* promote `.inline-pill` into `glass.css`/`utilities.css` as the static sibling of `.btn-pill`. Cite: `WordHeader.vue:70,96,128`.
- **G4 — Word-diff primitive.** `definition/components/InlineDiff.vue` + `TextDiffBlock.vue` + `versioning/VersionDiffViewer.vue` implement inline text-diff rendering (add/remove spans) — a reusable primitive with no canon equivalent (glass-ui has no `diff` component). *Proposal:* a `custom/inline-diff` primitive in glass-ui if other consumers (latex-paper, version histories) want it; otherwise leave consumer-local. Cite: `InlineDiff.vue` (53 lines), `TextDiffBlock.vue`.

## Union candidates (same pattern, both libraries, different vocabulary)

- **U1 — Toast / Notification.** Both libraries own a toast surface: glass-ui `Toaster.vue`/`Notification.vue` (`z-toast`, reka swipe, `--success`/`--info` intents) and words `NotificationToast.vue` (`Teleport`+`TransitionGroup`, `--color-success/info/gold` soup, `shadow-cartoon-sm` glass). Same widget, two vocabularies, both mounted. *Canonical:* glass-ui `<Toaster>`/`useToast` (already imported in words) — retire `NotificationToast.vue`.
- **U2 — Sidebar.** words has a `custom/Sidebar.vue` + a whole `custom/sidebar/*` + `custom/navigation/*` family; glass-ui ships a `custom/sidebar` register and `ProgressiveSidebar`-style patterns. Both implement collapsible glass side-rails. *Canonical:* converge on glass-ui's sidebar primitives where shape matches; keep words' wordlist-specific content slots. (Lower confidence — words' sidebar is content-heavy and may justifiably stay local; flagged as a vocabulary-union opportunity, not asserted drift.) Cite: `custom/Sidebar.vue:7,38` (uses `glass-floating`/`glass-wash`/`glass-overlay` correctly — the surface is already canon; only the component duplication is the union question).
- **U3 — Paper-texture surface.** words `index.css` `.dialog-surface`/`.card-surface`/`.paper-texture-overlay` apply `var(--paper-clean-texture)` + `background-blend-mode: multiply`; glass-ui ships `.paper-grain-overlay`/`.paper-underpaint` (`paper.css`) for the same effect. *Canonical:* glass-ui's `.paper-grain-overlay` over the `.glass-*` tier.
