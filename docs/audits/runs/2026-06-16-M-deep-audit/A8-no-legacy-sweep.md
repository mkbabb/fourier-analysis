# A8 — No-Legacy / Workaround Sweep
**Auditor:** A8 | **Date:** 2026-06-16 | **Tranche target:** M (ordering ξ′)

---

## Verdict

**17 findings** across 5 categories: (1) dead CSS shims, (2) glass-tier correctness (the dirty glass-subtle→glass-quiet rename is SEMANTICALLY WRONG — glass-wash is the correct 4.0 successor), (3) manual rAF loops duplicating keyframes.js, (4) duplicated color utility (`spectrumColor` × 4 distinct bodies), (5) !important hacks. One dead component (CanvasOverlayButton, zero consumers). The `cartoon-card` shim (D.W4.a) is the most chronic outstanding legacy debt — 22 application sites behind a fourier-local `@utility` patch vs. the glass-ui `glass-card` tier it should compose. The `animation.ts` manual rAF ping-pong loop is the second chronic: it was noted as a keyframes.js migration candidate since the auto-play migration and never converted.
